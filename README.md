# 🎟️ DK Booking

DK Booking is a full-stack ticket booking platform (movies, events, plays, sports, concerts, comedy and workshops) inspired by BookMyShow.

| Part | Tech | Folder |
|------|------|--------|
| Customer website (desktop + mobile) | React 18 + Vite | `frontend/` |
| Admin panel | React (`/admin`) | `frontend/src/pages/admin` |
| Agent panel | React (`/agent`) | `frontend/src/pages/agent` |
| REST API | Node.js + Express | `backend/` |

## Run locally

```bash
# API  -> http://localhost:5000
cd backend && npm install && npm run dev

# Web  -> http://localhost:5173
cd frontend && npm install && npm run dev
```
